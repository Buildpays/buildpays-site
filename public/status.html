If this page says everything is fine but it isn't for you

Two things are worth trying before you call. Pull down to refresh the app — a phone holds an old copy of a page for longer than you would think. Then check whether it is only your site's mobile signal: if the page loads on wifi but not on site, that is the network, not PayKicker.

If neither helps, tell us. A report from you is worth more than a monitor, because you can see what the monitor cannot: which screen, which button, and what it said.

Honest limitation. This status page is hosted separately from the application, so it stays up when PayKicker is down. But no status page can report an outage that takes out the page itself. If this page will not load either, assume there is a problem and phone us.

What we do during an incident

  • We tell the affected customers directly. You are a small number of businesses, not an anonymous user base, so you get an email or a call rather than only a page to refresh.
  • We keep written incident notes from the first report: what was seen, what was affected, what we did, and what we changed afterwards so it does not happen twice.
  • If personal information was exposed, our data breach response plan applies: assessment, notification to the affected people and to the Office of the Australian Information Commissioner where the law requires it, and a written review.

PayKicker does not publish an uptime guarantee. We would rather state that plainly than print a number we have not measured over enough time to stand behind.
