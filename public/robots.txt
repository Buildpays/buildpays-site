# SELF-SUFFICIENT ON PURPOSE. The BuildPays version carried only the Sitemap line
# and relied on Cloudflare's managed robots.txt (AI Crawl Control) being PREPENDED
# at the edge to supply the AI-crawler blocks. That was a per-zone setting on the
# buildpays.com.au zone — the new paykicker.com.au zone does not have it, so the
# blocks would have silently disappeared at the rebrand. They are written out here
# so this file is correct whether or not the zone feature is ever switched on.
#
# CONFIRMED 18 Aug 2026: AI Crawl Control IS enabled on this zone. The served file
# is the merge of the managed block and this one, so most directives appear twice.
# A duplicated Disallow is harmless; a missing one is not.
#
#   curl https://paykicker.com.au/robots.txt
#
# GOOGLE-EXTENDED IS DELIBERATELY ABSENT. It was removed so PayKicker content is
# eligible for Google's AI Overviews and AI Mode. It has never had any bearing on
# ordinary Search indexing — Googlebot governs that, and Googlebot is allowed below.
# WARNING: the Cloudflare managed block STILL disallows Google-Extended, and it is
# prepended to this file at the edge. Removing it here alone does nothing. It must
# also be unblocked in the Cloudflare dashboard under AI Crawl Control for the zone.
# Verify with the curl above before assuming it took effect.
#
# /paykicker-worker-training is intentionally NOT disallowed. It carries a noindex
# meta tag, and a crawler must be able to fetch the page to see that tag.
